# 项目文档地图

## 这是什么

一个基于 **NapCat（OneBot 11 正向 WebSocket）** 的 QQ 群聊机器人：

- 实时接收群消息，本地持久化（JSONL + SQLite 双份）
- 群里 **@机器人** 触发「群聊概括」（LLM 生成）与「AI 群聊」（带上下文记忆）
- **@机器人 说指令**时走确定性指令（词典学习/干员查询/抽卡/统计等），不消耗 LLM
- 每天 9:00 私聊发送「昨日活跃群日报」
- AI 回答带**三级知识库**：本地梗词典 → PRTS.Wiki（方舟）→ 萌娘百科（通用 ACG），另有可选维基百科
- 本地明日方舟数据库（干员/档案/藏品/卡池）支持秒回查询与真实卡池抽卡
- 附带 Web 管理面板（`http://127.0.0.1:5210`）

技术底座：Node.js ESM（≥22.5，因使用 `node:sqlite`），运行时唯一 npm 依赖 `ws`，其余全用 Node 内置能力（`fetch`、`node:http`、`node:sqlite`）。

## 源码注释规范（house style）

项目内所有源码注释遵循以下约定，新增/维护代码时请遵守：

1. **文件头注释**：每个源文件顶部用块注释写明「文件作用 / 关键对外接口 / 依赖与实例化点 / 读写的数据或配置」。1–2 段，中文，不写废话。
2. **导出符号 JSDoc**：每个 `export` 的类、函数、常量前加 `/** … */`，内容含：
   - 一句话职责；
   - `@param {类型} 名 - 说明`（类型用 JS 原生记法：`{string}` `{number}` `{boolean}` `{string[]}` `{Object}` `{Function}` `{Promise<string>}` 等）；
   - `@returns {类型}` 与返回值语义（`null` 何时返回等）；
   - `@throws` 仅在有意义的失败点时写；
   - 有外部副作用（写盘、发消息、改状态）时用 `副作用:` 单行点明。
3. **类的公开方法 JSDoc**：与导出符号同等对待；私有方法/短内部函数只加一行内联说明或轻量 `//` 注释。
4. **注释语言**：中文；不重复代码本身已自明的内容；`//` 用于解释「为什么/边界条件」，`/** */` 用于「是什么/怎么调用」。
5. **禁止事项**：注释不得改动任何代码语义；不得添加「自动生成」类空话；不得把一段话拆成多行 ASCII 艺术框。
